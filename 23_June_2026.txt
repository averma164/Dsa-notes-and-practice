# 15. 3Sum

Given an integer array nums, return all the triplets [nums[i], nums[j], nums[k]] such that i != j, i != k, and j != k, and nums[i] + nums[j] + nums[k] == 0.

# Approach :-

Two Pointer + Sorting
1) First, sort the array to make duplicate handling easier.
2) Fix one element i and use two pointers (j, k):
    - j = i + 1
    - k = n - 1
3) Calculate sum:
    - If sum < 0 → move j++
    - If sum > 0 → move k--
    - If sum == 0 → store the triplet in ans vector
4) Skip duplicates for:
    - i, j, k
5) Return ans

# Complexity :-

- Time Complexity: O(n^2)
- Space Complexity: O(1)

# Program :-

class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        int n = nums.size();
        vector<vector<int>> ans;
        sort(nums.begin(),nums.end());
        for(int i=0; i<n ; i++){
            if(i > 0 && nums[i] == nums[i-1]){
                continue;
            }
            int j = i+1, k = n-1;
            while(j<k){
                int sum = nums[i] + nums[j] + nums[k];
                if(sum < 0){
                    j++;
                }else if(sum > 0){
                    k--;
                }else{
                    ans.push_back({nums[i] , nums[j] , nums[k]});
                    j++;k--;
                    while(j < k && nums[j] == nums[j-1]){
                        j++;
                    }
                    while(j < k && nums[k] == nums[k + 1]) {
                        k--;
                    }
                }
            }
        }
        return ans;
    }
};
