# 73. Set Matrix Zeroes
Given an m x n integer matrix matrix, if an element is 0, set its entire row and column to 0's.

# Approach:-
To Solve the problem efficiently, We reuse the first column and first row as marker to track which row and wich column should be set zero.
1) Check First Row & First Column Use two flags:-
    - x → indicates if the first row should be zero
    - y → indicates if the first column should be zero
2) Mark Rows and Columns.Traverse the matrix starting from (1,1)
    - If matrix[i][j] == 0:
      - Set matrix[i][0] = 0 → mark row
      - Set matrix[0][j] = 0 → mark column
3) Zero Out Columns, For each column j:-
    - If matrix[0][j] == 0, set entire column j to zero
4) Zero Out Rows, For each row i:-
    - If matrix[i][0] == 0, set entire row i to zero
5) Handle First Column:-
    - If y == 0, set entire first column to zero
6) Handle First Row:-
    - If x == 0, set entire first row to zero

# Complexity Analysis:-

- Time Complexity: O(m × n)
- Space Complexity: O(1) (no extra space used)

# Program:-

class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int m = matrix.size();
        int n = matrix[0].size();
        int x = 1, y = 1;

        for(int j = 0; j < n; j++){
            if(matrix[0][j] == 0){
                x=0;
            }
        }
        for(int i = 0; i < m; i++){
            if(matrix[i][0] == 0){
                y=0;
            }
        }
        for(int i = 1; i < m; i++){
            for(int j = 1; j < n; j++){
                if(matrix[i][j] == 0){
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }
        for(int j = 1; j < n; j++){
            if(matrix[0][j] == 0){
                for(int i = 0; i < m; i++){
                    matrix[i][j] = 0;
                }
            }
        }
        for(int i = 1; i < m; i++){
            if(matrix[i][0] == 0){
                for(int j = 0; j < n; j++){
                    matrix[i][j] = 0;
                }
            }
        }
        if(y==0){
            for(int i = 0; i < m ;i++){
                matrix[i][0] = 0;
            }
        }
        if(x==0){
            for(int j = 0; j < n ;j++){
                matrix[0][j] = 0;
            }
        }
        
    }
};
