# 206. Reverse Linked List

Head of a singly linked List is Given. return the head of Reversed Linked List.

# Approach:-

1) Make two Pointers:-
    - curr = head,
    - prev = NULL.
2) Visite the Nodes Till:-
    - curr != NULL.
3) Make a new Pointer:-
    - nextNode = curr->next;
4) Update the values:-
    - curr->next = prev,
    - prev = curr,
    - curr = nextNode.
5) When the loop ends:-
    - Return prev.
   Which is the head of the reversed Linked List.

# Program:-

class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* curr = head;
        ListNode* prev = NULL;
        while(curr != NULL){
            ListNode* nextNode = curr->next;
            curr->next = prev;
            prev = curr;
            curr = nextNode;
        }
        return prev;
    }
};
