# 19. Remove Nth Node From End of List

Given the head of a linked list, remove the nth node from the end of the list and return its head.

# Approach :-

This problem can be solved efficiently using the Two Pointer (Fast & Slow Pointer) technique.
1) Initialize two pointers: temp1 and temp2 at the head.
2) Move temp1 ahead by n nodes.
3) If temp1 becomes NULL, it means the node to remove is the head.
4) Otherwise, move both pointers together until temp1 reaches the last node.
5) Now, temp2 will be just before the node that needs to be deleted.
6) Update the links and delete the target node.

# Complexity :-

- Time Complexity : O(N)
- Space Complexity : O(1)

# Program :-

class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode* temp1 = head;
        ListNode* temp2 = head;
        while(n > 0){
            temp1 = temp1->next;
            n--;
        }
        if(temp1 == NULL){
            ListNode* deletedNode = head;
            head = head->next;
            delete deletedNode;
            return head;
        }
        while(temp1->next != NULL){
            temp2 = temp2->next;
            temp1 = temp1->next;
        }
        ListNode* deletedNode = temp2->next;
        temp2->next = deletedNode->next;
        delete deletedNode;
        return head;
    }
};
