# 1967. Number of Strings That Appear as Substrings in Word

Given an array of strings patterns and a string word, return the number of strings in patterns that exist as a substring in word.
A substring is a contiguous sequence of characters within a string.

# Approach :-

1) Iterate through each string in the `patterns` array.
2) Use C++'s built-in `find()` function to check whether the current pattern exists as a substring of `word`.
3) If `find()` does not return `string::npos`, the pattern is present, so increment the count.
4) Return the total count after checking all patterns.

# Complexity :-

- Time Complexity : O(n × m × k)  (worst case)
  - n = number of strings in `patterns`
  - m = length of `word`
  - k = average length of a pattern
- Space Complexity : O(1)

# Program :-

class Solution {
public:
    int numOfStrings(vector<string>& patterns, string word) {
        int count = 0;
        for (string pattern : patterns) {
            if (word.find(pattern) != string::npos) {
                count++;
            }
        }
        return count;
    }
};
