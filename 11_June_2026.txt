# 347. Top K Frequent Elements

Given an integer array nums and an integer k, return the k most frequent elements. You may return the answer in any order.

# Approach :-

1) Check if nums.size() < 1 if yes return nums
2) Initialize unordered_map and j = 0
3) Inside a while loop 
   Check if m has nums[j] if yes increase the value
   If not put nums[j] with value 1
4) Initialize vector
   vector<pair<int,int>> v
   vector<int> result;
5) Store m in v using a for loop
6) Sort v in reverse
7) Add the elements k times in result
8) Return result

# Complexity :-

- Time Complexity:- O(n log n)
- Space Complexity :- O(n)

# Program :-
class Solution {
public:
    vector<int> topKFrequent(vector<int>& nums, int k) {
        if (nums.size() < 1){
            return nums;
        }
        unordered_map<int,int> m;
        int j = 0;
        while(j < nums.size()){
            if(m.find(nums[j]) != m.end()){
                m[nums[j]] += 1;
            }else{
                m[nums[j]] == 1;
            }
            j++;
        }
        vector<pair<int,int>> v;
        for(auto &p : m){
            v.push_back({p.second, p.first});
        }
        sort(v.rbegin(), v.rend());
        vector<int> result;
        for(int i = 0; i < k; i++){
            result.push_back(v[i].second);
        }
        return result;
    }
};
