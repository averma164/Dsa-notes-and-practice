# 2144. Minimum Cost of Buying Candies With Discount
Whenever you buy 2 candies, you get 1 candy for free — but the free one must be equal or cheaper than the ones you bought.

# Approach:-
1) Sort the array in descending order,So the most expensive candies come first.
    {
      sort(cost.begin(),cost.end(), greater<int>());
    }
    
2) Pick candies in groups of 3
3) Pay for the first 2 and Skip the 3rd one (free candy)
    {
      if((i % 3) != 2)
    }
4) Keep adding the cost of only the candies you pay for.
    {
      ans += cost[i];
    }
# Program :-
class Solution {
public:
    int minimumCost(vector<int>& cost) {
        sort(cost.begin(),cost.end(), greater<int>());
        int ans = 0;
        for(int i = 0; i < cost.size(); i++) {
            if((i % 3) != 2) { 
                ans += cost[i];
            }
        }
        return ans;
    }
};
